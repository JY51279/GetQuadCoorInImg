# 桌面版人工冒烟检查

自动化测试覆盖数据模式、运行状态、坐标与 Quad 几何、保存回滚、IPC 处理以及关键 Vue 交互。以下检查只用于验证 Electron 桌面环境、原生文件对话框和真实文件系统之间的连接；发布前不需要另建一套完整的端到端测试。

## 准备

1. 执行 `npm run check`，确认格式、全部自动化用例、ESLint 和生产构建通过。
2. 执行 `npm run dev`。
3. 准备一份可修改的测试 JSON 及其图片副本；不要直接使用唯一的正式数据副本。

## 数据集与图片

- 分别打开一份 DBR、DDN 和 DLR 数据集，确认产品类型、图片数量和第一张图片正确。
- 至少验证一个相对图片路径和一个绝对图片路径，确认前后图片切换及首尾循环正常。
- 取消 JSON 或图片选择对话框，确认当前数据和图片不被清空。
- 打开包含无损规范化项的数据副本，确认规范化后能够保存并继续加载。
- 打开需要有损修复的数据副本：取消时原文件不变；确认时加载成功，并在应用数据目录生成临时备份。

## Quad 编辑与交互

- 用鼠标移动到不同 Quad 上，确认开启悬停联动时只激活唯一命中的 Quad；关闭后不随悬停切换。
- 在图片上依次选择、取消 P1–P4，确认最多保留四点，并能用 `1`–`4`、`C`、撤回和重做快捷键更新选点。
- 分别执行新增、更新和删除，确认画布、右侧数据、数量字段和磁盘 JSON 一致。
- 在第二张及之后的图片中激活一个 Quad，点击“沿用上图坐标”或按 `Ctrl+E`，确认只复制上一张图片同下标 Quad 的坐标，并可通过 JSON 历史撤销和重做。
- 拖动当前 Quad 的四个顶点，确认释放后只生成一次保存和一条历史记录；按 `Esc` 取消拖动时不保存。
- 拖动当前 Quad 的中心橙色手柄，确认四点保持形状整体移动，触及图片四边时不会越界或变形；拖动期间把鼠标移入其他 Quad、按 `W`/`S` 或方向键，当前激活下标均不改变。释放后只保存一次并生成一条“整体平移 Quad”历史记录；按 `Esc` 取消时恢复原位置且不保存。
- 在操作历史中执行单步撤销、重做和跨多步跳转，确认只保存一次且最终画布与 JSON 一致。

## 视口与边界吸附

- 在 Windows 100%、125% 或 150% 显示缩放下调整窗口大小，确认工具栏、侧栏文字在松开窗口边框后保持清晰，图片、Quad 描边和像素预览没有被低分辨率缓冲区放大；如有多台不同 DPI 的显示器，再将窗口跨屏移动验证一次。
- 缩小或放大图片后从四个方向拖到视口边界，确认图片先吸附；继续向同一方向累计移动约 10 像素后应能脱离边界。
- 让图片宽度或高度恰好贴合视口，确认仍可从重合边界拖离，不会卡住。
- 验证滚轮缩放、比例输入、比例滑杆、`R` 重置、`F` 聚焦 Quad 和 `Z` 聚焦鼠标像素。
- 放大到像素网格模式，确认网格、选点位置、Quad 顶点及取色预览仍对齐。

## 保存失败回滚（可选）

1. 使用测试副本加载数据集，然后暂时将 JSON 文件设为只读。
2. 执行一次明显的 Quad 修改，确认界面提示保存失败，画布和内存数据恢复到修改前状态，历史不增加。
3. 恢复文件可写状态并重新执行修改，确认保存成功。

完成上述项目且没有新错误日志，即可认为桌面版主流程通过人工冒烟检查。
